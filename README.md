# Греческие слова

Мобильное веб-приложение для заучивания греческих слов.
Статический сайт: один `index.html` плюс файл с наборами слов `words.js`. Серверная часть не нужна.

## Режимы

1. Карточки греческий → русский (можно отмечать изученные, учить все или только неизученные)
2. Карточки русский → греческий
3. Учимся писать: собрать греческое слово из букв вразброс
4. Пишем сами: ввести греческое слово с клавиатуры
5. Варианты ответа: тест с четырьмя вариантами в обе стороны, в том числе только по неизученным словам

Прогресс хранится в `localStorage` браузера. В настройках можно импортировать свой набор, вставив список слов.

## Структура

- `index.html` — приложение (разметка, стили, логика)
- `words.js` — наборы слов: `window.WORD_SETS = [{ id, title, words: [{ gr, ru }] }]`

## Как добавить набор

Добавьте в `words.js` ещё один объект в массив `WORD_SETS`. Варианты ответа на греческом можно
перечислять через `/` (например `γεια σου / γεια σας`) — в режимах письма засчитывается любой из них.

## Публикация на GitHub Pages

1. Создайте репозиторий и запушьте код в ветку `main`.
2. Settings → Pages → Source: «Deploy from a branch», Branch: `main`, папка `/ (root)`.
3. Через минуту приложение откроется по адресу `https://<user>.github.io/<repo>/`.
4. Добавьте страницу на домашний экран телефона («Поделиться» → «На экран Домой»).
