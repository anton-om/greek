# Греческие слова

Мобильное веб-приложение для заучивания греческих слов.
Статический сайт: один `index.html` плюс файл с наборами слов `words.js`. Серверная часть не нужна.

## Режимы

1. Карточки греческий → русский (можно отмечать изученные, учить все или только неизученные)
2. Карточки русский → греческий
3. Варианты ответа греческий → русский
4. Варианты ответа русский → греческий
5. Учимся писать: собрать греческое слово из букв вразброс
6. Пишем сами: ввести греческое слово с клавиатуры, ударения учитываются

На экране настройки каждого режима выбираются слова: все или неизученные, с дополнительной
лексикой или без, все или случайные 30. Ошибки повторяются в том же сеансе; после тестов и
письма предлагается обновить список изученных. Есть шпаргалка: алфавит, сочетания букв,
дифтонги, ударение.

Прогресс хранится в `localStorage` браузера. В настройках можно импортировать свой набор, вставив список слов.

## Структура

- `index.html` — приложение (разметка, стили, логика)
- `words.js` — наборы слов: `window.WORD_SETS = [{ id, title, words: [{ gr, ru }], extra: [{ gr, ru }] }]`
- `docs/adding-lessons.md` — правила добавления новых уроков и слов
- `docs/quizlet-mechanics.md` — обзор механик Quizlet и идеи для развития

## Как добавить набор

См. [docs/adding-lessons.md](docs/adding-lessons.md). Коротко: добавьте в `words.js` ещё один
объект в массив `WORD_SETS` с уникальным `id`, названием, основной лексикой `words` и, при
желании, дополнительной `extra`. Варианты ответа на греческом можно перечислять через `/`
(например `γεια σου / γεια σας`), в режимах письма засчитывается любой из них.

## Публикация на GitHub Pages

1. Создайте репозиторий и запушьте код в ветку `main`.
2. Settings → Pages → Source: «Deploy from a branch», Branch: `main`, папка `/ (root)`.
3. Через минуту приложение откроется по адресу `https://<user>.github.io/<repo>/`.
4. Добавьте страницу на домашний экран телефона («Поделиться» → «На экран Домой»).
