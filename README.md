# Греческие слова

Мобильное веб-приложение для заучивания греческих слов.
Статический сайт: один `index.html` плюс файл с наборами слов `words.js`. Серверная часть не нужна.

## Режимы

1. Карточки греческий → русский (можно отмечать изученные, учить все или только неизученные)
2. Карточки русский → греческий
3. Варианты ответа греческий → русский
4. Варианты ответа русский → греческий
5. Учимся писать: собрать греческое слово из букв вразброс
6. Пишем сами: ввести греческое слово с клавиатуры, ударения учитываются
7. Множественное число: к основе существительного вписать артикль и окончание в единственном
   и множественном числе
8. Спряжение глаголов: по русской форме («он учит») написать греческую форму глагола;
   лицо выбирается случайно, по одному на глагол
9. Отработка лексики: прочитать вслух греческое предложение со словом; браузер распознаёт речь
   (Chrome на Android и настольные браузеры) и подсвечивает нераспознанные слова; слова
   сравниваются по звучанию, так что омофонное написание (τις/της) не считается ошибкой. Если в
   настройках есть ключ OpenAI или OpenRouter с моделью 🎤, запись той же попытки можно отправить
   модели: она пишет, что услышала, ставит оценку произношения от 0 до 6 (три кружка) и
   объясняет по-русски, что не так; на iPhone,
   где распознавание в браузере не работает, это единственный и основной способ. Кнопку
   микрофона держат, пока говорят. В браузерах без распознавания речи вместо кнопки поле
   ввода. На iPhone режимы 9 и 10 не показываются: распознавание речи в WebKit не работает
   (`docs/ios-speech-recognition.md`). Режимы помечены «в разработке» до проверки на Android
10. Отработка лексики с русского: то же, но показан только русский перевод предложения
11. Занятие с ИИ: голосовое занятие с языковой моделью словами выбранного набора; чем
    заняться (диалог, слова, вопросы), ученик говорит по-русски, кнопку микрофона держит, пока
    говорит; модель отвечает голосом, новые слова помечает и переводит, ошибки объясняет
    по-русски. С ключом OpenAI или OpenRouter (модели 🎤) модели уходит запись голоса, и она сама
    понимает греческий и русский; с ключом Anthropic речь распознаёт браузер. На iPhone режим
    работает только с записью голоса в модель.
    Подробности: `docs/dialog-mode.md`

Под выбором набора на главном экране настраивается тренировка: основная и дополнительная
лексика урока, части речи (существительные, глаголы, прилагательные, остальное), все слова
или только неизученные, перемешивание. Нажатие на режим сразу
запускает тренировку. Ошибки повторяются в том же сеансе; после тестов и
письма предлагается обновить список изученных. На главном экране словарь выбранного набора
с поиском и озвучкой. Есть шпаргалка: алфавит, сочетания букв,
дифтонги, артикли, окончания существительных, спряжение глаголов, ударение.

В селекторе наборов есть вариант «Custom»: сборный набор из выбранных уроков, для каждого урока
отдельно включается основная и дополнительная лексика; переключатели частей речи (существительные,
глаголы, прилагательные, остальное) сужают этот набор, по умолчанию включены все.

Отметка «изучено» принадлежит слову и общая для всех уроков, где оно встречается. Ставится
вручную в карточках и после тестов, а также сама: если слово в режиме «Пишем сами» дважды
написано верно с первого раза и без подсказки (ошибка обнуляет счёт). Прогресс хранится в
`localStorage` браузера.

Приложение работает без интернета: service worker держит в кеше страницу, файлы данных и иконки.
Без сети недоступны только режимы с распознаванием речи и моделью (9, 10, 11), они помечаются
«нет сети». События метрик без сети копятся локально и досылаются при подключении. В настройках можно импортировать свой набор, вставив список слов.

## Структура

- `index.html` — приложение (разметка, стили, логика)
- `words.js` — наборы слов: `window.WORD_SETS = [{ id, title, words: [{ gr, ru, pos }], extra: [{ gr, ru, pos }] }]`
- `grammar.js` — формы множественного числа существительных и спряжения глаголов для режимов 7 и 8
- `sentences.js` — по 5 предложений на каждое слово для режимов 9 и 10
- `docs/adding-lessons.md` — правила добавления новых уроков и слов
- `docs/quizlet-mechanics.md` — обзор механик Quizlet и идеи для развития

## Как добавить набор

См. [docs/adding-lessons.md](docs/adding-lessons.md). Коротко: добавьте в `words.js` ещё один
объект в массив `WORD_SETS` с уникальным `id`, названием, основной лексикой `words` и, при
желании, дополнительной `extra`. Варианты ответа на греческом можно перечислять через `/`
(например `γεια σου / γεια σας`), в режимах письма засчитывается любой из них.

## Установка на экран «Домой»

Есть `manifest.webmanifest` и иконки в `icons/` (сгенерированы из «Gr» на синем фоне), поэтому
добавленное на экран «Домой» приложение открывается без адресной строки. На главном экране в
браузере показывается блок «Добавить приложение»: на Android/Chrome он вызывает системный диалог
установки, на iPhone показывает инструкцию (Поделиться → На экран «Домой»), потому что API для
этого в Safari нет. Внутри установленного приложения и после «Скрыть» блок не показывается.
Хранилище у Safari и у установленного приложения разное, прогресс между ними не переносится.

## Метрики

Счётчик посещений — [GoatCounter](https://www.goatcounter.com): бесплатный для личных проектов,
без cookie, показывает уникальных посетителей по дням. В `index.html` в константу `ANALYTICS_CODE`
вписывается код сайта из аккаунта GoatCounter; панель открывается по адресу
`https://<код>.goatcounter.com`. Пока код пустой, ничего не подключается. Помимо просмотров
страницы отправляются события: запуск каждого режима (`mode/<режим>`), завершение тренировки
(`done/<режим>`), открытие шпаргалки (`cheat`) и первое открытие на устройстве (`new-device`,
один раз на браузер по отметке в `localStorage`). В панели GoatCounter они видны по дням.
Посетителей GoatCounter считает уникальными только в пределах дня, по IP и браузеру, без cookie.

Сводку можно получить из терминала через API: `scripts/metrics.py --days 7` печатает таблицу по
дням (посетители, просмотры, запуски каждого режима, завершения, шпаргалка), `--json` отдаёт сырые
данные. Токен создаётся в панели GoatCounter (меню пользователя → API, право «Read statistics»)
и кладётся в `~/.config/goatcounter/learn-greek.token` или в переменную `GOATCOUNTER_TOKEN`.
В репозиторий токен не попадает (`*.token` в `.gitignore`).

## Публикация на GitHub Pages

1. Создайте репозиторий и запушьте код в ветку `main`.
2. Settings → Pages → Source: «Deploy from a branch», Branch: `main`, папка `/ (root)`.
3. Через минуту приложение откроется по адресу `https://<user>.github.io/<repo>/`.
4. Добавьте страницу на домашний экран телефона («Поделиться» → «На экран Домой»).
