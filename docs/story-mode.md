# Экран «Рассказ о себе»

Подготовка устного рассказа о себе (ответы на вопросы экзамена A2) по собственному тексту ученика.
У каждого ученика свой текст, и он не должен попадать к другим, поэтому в репозитории рассказов нет:
текст живёт только в браузере ученика.

## Откуда берётся текст

Ссылка на Google Документ вводится в настройках, раздел «Рассказ о себе». Документ должен быть
открыт по ссылке для чтения («Поделиться» → «Все, у кого есть ссылка» → «Читатель»). Приложение
запрашивает `https://docs.google.com/document/d/<ID>/export?format=txt`: для открытых документов
Google отвечает с заголовком `Access-Control-Allow-Origin`, так что текст читается из браузера без
сервера (проверено 2026-11-12; закрытый документ отдаёт редирект на страницу входа, и запрос падает
по CORS, приложение показывает подсказку про доступ). Результат разбора хранится в `localStorage`
под ключом `greek-words:story` отдельно от прогресса, поэтому сброс прогресса его не трогает;
«Удалить рассказ» в настройках стирает его.

## Формат документа

Разделы начинаются с номера: `1. Как вас зовут? / Πώς σας λένε;`. Строка вопроса делится по `/`:
русская часть показывается как заголовок, греческая озвучивается кнопкой рядом. Строки ниже до
следующего номера относятся к разделу: строки с греческими буквами — ответ (озвучивается и
проверяется), остальные — русская подсказка. Разделы без греческих строк пропускаются. Если в
документе нет нумерации, разделами считаются абзацы, разделённые пустой строкой. Политонические
знаки, набранные по ошибке (ὼ, ὲ), приводятся к обычному ударению. Первая строка документа до
первого номера считается названием рассказа.

## Что умеет экран

На главном экране кнопка «Рассказ о себе» появляется сразу после шпаргалки, только когда рассказ
загружен. На экране: название, число разделов, «Обновить из документа» (повторная загрузка по
сохранённой ссылке), переключатель «Скрыть греческий» (прячет ответы, чтобы рассказывать по памяти
по русской подсказке; «Показать» открывает один раздел). В каждом разделе:

- 🔊 «Озвучить» — греческий ответ целиком греческим голосом синтеза речи;
- 🎤 — кнопка удержания: пока нажата, идёт запись (WAV 16 кГц, как в режимах 9–13), после
  отпускания запись уходит модели той же функцией `aiSpeechCheck`, что и в речевых режимах, с
  заданием «ученик рассказывает о себе наизусть по своему тексту». Эталон (греческий текст раздела)
  идёт в запросе после записи. Ответ: три кружка оценки 0–6, что модель услышала, комментарий
  по-русски и время ответа. Пересказ своими словами не считается ошибкой произношения: модель
  отмечает, что пропущено, а оценку ставит за произношение сказанного.

Кнопка 🎤 показывается только если в настройках есть ключ с моделью, принимающей звук
(`aiAudioPossible()`), и есть сеть; без ключа экран работает как озвучка. Текст и запись уходят
только провайдеру модели, которого выбрал ученик, как и в остальных речевых режимах.

## Метрики

События GoatCounter: `story` (открытие экрана), `story-load` (успешная загрузка документа),
`story-check` (проверка раздела моделью). Содержимое рассказа никуда не отправляется.

## Что дальше

Когда появится бэкенд (см. `docs/backend.md`), ссылка на документ и разобранный текст могут
синхронизироваться между устройствами ученика вместе с прогрессом: это текст, а не аудио, и он
относится к одному аккаунту.
