# Идеи: небольшой бэкенд

Сейчас приложение — статический сайт на GitHub Pages, всё хранится в `localStorage`, метрики
считает GoatCounter. Ниже — что даст свой бэкенд и где его держать. Пока не сделано.

## Где хостить

| Вариант | Цена | Плюсы | Минусы |
|---|---|---|---|
| **Cloudflare Workers + D1** (SQLite) | бесплатно: 100 тыс. запросов в день, 5 ГБ | не засыпает, деплой одной командой, можно повесить на свой домен | нужен аккаунт Cloudflare |
| Supabase (Postgres + REST) | бесплатно | готовая база и API без своего кода | бесплатный проект засыпает после недели без активности |
| Deno Deploy + Deno KV | бесплатно | очень просто, JS | KV неудобен для аналитических запросов |
| Vercel / Netlify Functions | бесплатно | привычно | своей базы нет, нужна внешняя |
| VPS (Hetzner и т. п.) | ~4 €/мес | полная свобода | обновления и бэкапы на себе |

Предпочтительный вариант — Cloudflare Workers + D1: код воркера и SQL-схема в этом же
репозитории (папка `worker/`), цифры смотреть через закрытую страницу или `wrangler`.

## Статистика

GoatCounter помнит уникальность посетителя только в пределах дня и режется блокировщиками.
Свой эндпоинт на своём домене позволит считать:

- уникальных пользователей за всё время — по анонимному случайному ID в `localStorage`,
  без cookie и личных данных;
- удержание: сколько возвращаются через день, через неделю;
- какие уроки и режимы реально проходят, сколько доходят до конца;
- в каких словах чаще всего ошибаются, по всем пользователям сразу.

## Личная статистика для пользователя

Отдельный экран «Моя статистика», где пользователь видит свою историю занятий:

- сколько раз пройден каждый режим по каждому уроку, когда последний раз;
- сколько раз повторено каждое слово и в каких режимах, сколько из них с ошибкой;
- самые трудные слова (больше всего ошибок) — с кнопкой «потренировать их»;
- дни занятий подряд, время занятий по дням и неделям, график изученных слов;
- для режимов 9 и 10 — сколько предложений распознано с первой попытки.

Часть этого можно считать и без бэкенда, в `localStorage`. Бэкенд добавляет синхронизацию
между устройствами (телефон, планшет), историю, которая не пропадает при очистке браузера,
и сравнение с общими цифрами («это слово трудное для большинства»). Для синхронизации нужен
вход: анонимный ID с кодом восстановления или вход по почте.

## Генерация предложений через AI

Режимы 9 и 10 («Отработка лексики») сейчас берут готовые предложения из `sentences.js`,
по 5 на слово. Бэкенд может дополнительно генерировать новые через Claude API:

- воркер принимает слово (или список слов сеанса) и уже изученную лексику, возвращает
  простые предложения с переводом в формате `sentences.js`; ключ API хранится только в воркере;
- предложения строятся из выбранной пользователем лексики, поэтому подстраиваются под то,
  что он учит сейчас, и не повторяются;
- готовые предложения остаются основой и запасным вариантом: без сети, при ошибке или
  долгом ответе режим работает на `sentences.js`;
- сгенерированное не проверено человеком, поэтому стоит кешировать удачные варианты
  в D1 и давать пользователю отметить ошибку в предложении;
- ограничить число запросов на устройство в день, чтобы держать стоимость под контролем.

## Режим «Диалог»

С LLM на бэкенде можно сделать разговорную практику:

- собеседник ведёт простой диалог на греческом по теме (знакомство, кафе, семья, погода),
  используя по возможности лексику выбранных уроков;
- ответ можно ввести текстом или сказать голосом: распознавание то же, что в режимах 9 и 10,
  реплики собеседника озвучиваются синтезом речи браузера;
- к каждой реплике есть русский перевод по нажатию;
- ошибки в ответах пользователя мягко поправляются: правильный вариант показывается
  под репликой, разговор продолжается;
- в конце — короткий разбор: какие слова урока использованы, типичные ошибки;
- история диалога хранится только на время сеанса; лимит реплик в день на устройство,
  как и для генерации предложений.
