# Как добавлять новые уроки

Все слова лежат в одном файле `words.js`. Приложение читает массив `window.WORD_SETS`,
каждый элемент которого — один набор (урок). Серверной части нет: после правки файла
достаточно закоммитить и запушить в `main`, GitHub Pages обновит сайт.

## Формат набора

```js
{
  id: "lesson-1-2",          // уникальный id, латиницей, не менять после публикации
  title: "Урок 1.2",         // название в списке наборов
  words: [                   // основная лексика урока
    { gr: "το σπίτι", ru: "дом", pos: "n" },
    { gr: "πηγαίνω", ru: "идти, ходить", pos: "v" }
  ],
  extra: [                   // необязательно: дополнительная лексика
    { gr: "μεγάλος", ru: "большой", pos: "adj" }
  ]
}
```

- `id` — ключ, по которому в `localStorage` хранится прогресс. Если его поменять,
  отметки «изучено» для этого набора пропадут.
- `words` — основная лексика, `extra` — дополнительная. Какая из них участвует в тренировке,
  выбирается переключателями «Основная» и «Дополнительная» под выбором набора на главном
  экране; в сборном наборе «Custom» то же самое задаётся для каждого урока отдельно.
- Прогресс по слову привязан к строке `gr`, поэтому одно и то же слово в `words`
  и `extra` одного набора недопустимо.

## Правила для слов

1. **Существительные с артиклем**: `ο πατέρας`, `η μητέρα`, `το παιδί`, `τα μαλλιά`.
   Артикль является частью ответа в режимах письма и показывает род.
2. **Глаголы в 1-м лице настоящего времени**: `έχω`, `κοιμάμαι`.
3. **Прилагательные в мужском роде**: `καλός`, `μεγάλος`.
4. **Ударения обязательны** во всех греческих словах: режим «Пишем сами» считает
   пропущенное ударение ошибкой.
5. **Фразы допустимы**: `Πώς σε λένε;`, `Με λένε…`. Пробелы и знаки препинания
   в конце (`; ? ! . …`) режимы письма не требуют вводить.
6. **Несколько вариантов ответа** перечисляются через `/`: `γεια σου / γεια σας`.
   В режимах письма засчитывается любой из них, в плитках собирается первый.
7. **Перевод** — короткий, в начальной форме, без скобок, если без них можно обойтись.
   Пояснение можно добавить после запятой или в скобках: `мой, моя (после слова)`.
8. Регистр в `gr` не важен для проверки: в режимах письма всё приводится к строчным.
9. **Часть речи** `pos`: `n` существительное, `v` глагол, `adj` прилагательное. По ней
   сборный набор «Custom» сужается до отмеченных частей речи из выбранных уроков. Наречия, местоимения, фразы и приветствия остаются без `pos` и попадают
   в категорию «Остальное».

## Правила для уроков

- Один набор = один урок курса. Название: `Урок 1.2`, `Урок 1.3` и так далее,
  id в том же стиле: `lesson-1-2`, `lesson-1-3`.
- Основная лексика берётся из списка слов урока целиком, без сокращений.
- Дополнительная лексика (`extra`) — слова из текстов, примеров и заданий урока,
  которых нет в основном списке. Сначала самые частые, ориентир 25 слов, но полезные
  слова, встретившиеся один раз, тоже можно включить. Предлоги, союзы и артикли
  не включаются.
- Основные слова не повторяются между уроками: если слово из списка нового урока
  уже есть в основной лексике предыдущего урока, в новый набор оно не добавляется.
- Дополнительные слова переносятся: слово из дополнительной лексики предыдущего
  урока, попавшее в список нового урока, добавляется в `words` нового урока и
  убирается из `extra` предыдущего. Дополнительное слово тоже не должно повторять
  ни основное, ни дополнительное слово другого урока.
- Внутри одного набора дубликаты запрещены.
- Порядок слов в `words` — как в материалах урока; режим карточек без
  перемешивания идёт в этом порядке.

## Проверка перед публикацией

```sh
node --check words.js
node -e "global.window={};require('./words.js');var S=window.WORD_SETS,seen={};S.forEach(s=>{var a=s.words.concat(s.extra||[]).map(w=>w.gr.toLowerCase());var d=a.filter((x,i)=>a.indexOf(x)!==i);console.log(s.id,s.words.length,(s.extra||[]).length,'dups:',d);a.forEach(g=>{if(seen[g])console.log('REPEAT',g,seen[g],'->',s.id);seen[g]=s.id})})"
```

Вторая команда печатает число слов в каждом наборе, дубликаты внутри набора и
строки `REPEAT` для слов, встречающихся в двух наборах. И того и другого быть не должно.

После правки `words.js` или `index.html` обновите номер сборки в `index.html`: он стоит
в двух местах, `<meta name="build" content="...">` и `<script src="words.js?v=...">`,
и должен совпадать. Удобно ставить дату с порядковым номером, например `2026-10-19-5`:

```sh
sed -i '' 's/2026-10-19-5/2026-10-20-1/g' index.html
```

По этому номеру приложение при каждом открытии сверяется с сервером и само
перезагружается, если вышла новая сборка. Состояние экрана и текущего упражнения
перед перезагрузкой сохраняется в `sessionStorage` и восстанавливается после неё,
так что обновление не сбивает процесс. Без смены номера телефоны могут до
десяти минут показывать старую версию из кеша GitHub Pages.
