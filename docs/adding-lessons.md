# Как добавлять новые уроки

Все слова лежат в одном файле `words.js`. Приложение читает массив `window.WORD_SETS`,
каждый элемент которого — один набор (урок). Серверной части нет: после правки файла
достаточно закоммитить и запушить в `main`, GitHub Pages обновит сайт.

## Формат набора

```js
{
  id: "lesson-1-2",          // уникальный id, латиницей, не менять после публикации
  title: "Урок 1.2",         // название в списке наборов
  words: [                   // основная лексика урока
    { gr: "το σπίτι", ru: "дом", pos: "n" },
    { gr: "πηγαίνω", ru: "идти, ходить", pos: "v" }
  ],
  extra: [                   // необязательно: дополнительная лексика
    { gr: "μεγάλος", ru: "большой", pos: "adj" }
  ]
}
```

- `id` — уникальный ключ набора; по нему хранятся настройки лексики и состав набора «Custom».
  Отметки «изучено» привязаны к строке `gr` слова, а не к набору, и общие для всех уроков.
- `words` — основная лексика, `extra` — дополнительная. Какая из них участвует в тренировке,
  выбирается переключателями «Основная» и «Дополнительная» под выбором набора на главном
  экране; в сборном наборе «Custom» то же самое задаётся для каждого урока отдельно.
- Прогресс по слову привязан к строке `gr`, поэтому одно и то же слово в `words`
  и `extra` одного набора недопустимо.

## Правила для слов

1. **Существительные с артиклем**: `ο πατέρας`, `η μητέρα`, `το παιδί`, `τα μαλλιά`.
   Артикль является частью ответа в режимах письма и показывает род.
2. **Глаголы в 1-м лице настоящего времени**: `έχω`, `κοιμάμαι`.
3. **Прилагательные в мужском роде**: `καλός`, `μεγάλος`.
4. **Ударения обязательны** во всех греческих словах: режим «Пишем сами» считает
   пропущенное ударение ошибкой.
5. **Фразы допустимы**: `Πώς σε λένε;`, `Με λένε…`. Пробелы и знаки препинания
   в конце (`; ? ! . …`) режимы письма не требуют вводить.
6. **Несколько вариантов ответа** перечисляются через `/`: `γεια σου / γεια σας`.
   В режимах письма засчитывается любой из них, в плитках собирается первый.
7. **Перевод** — короткий, в начальной форме, без скобок, если без них можно обойтись.
   Пояснение можно добавить после запятой или в скобках: `мой, моя (после слова)`.
8. Регистр в `gr` не важен для проверки: в режимах письма всё приводится к строчным.
9. **Часть речи** `pos`: `n` существительное, `v` глагол, `adj` прилагательное. По ней
   сборный набор «Custom» сужается до отмеченных частей речи из выбранных уроков. Наречия, местоимения, фразы и приветствия остаются без `pos` и попадают
   в категорию «Остальное».
10. **Тема** `t` обязательна у каждого слова, ключ из списка `window.TOPICS` в начале
    `words.js` (люди и семья, части тела, еда, дом, вещи, природа, места, время, времена года,
    понятия; группы глаголов, прилагательных; наречия, предлоги, местоимения, числительные, приветствия,
    вопросы). По теме в режимах с вариантами ответа подбираются дистракторы (кухонные предметы —
    к кухонным предметам), а на главном экране лексику урока и набор Custom можно сузить до отмеченных тем.
    Новую тему добавлять в `TOPICS` только если слов в ней наберётся хотя бы 4–5; иначе
    выбирать ближайшую существующую. `scripts/check-words.js` требует тему у каждого слова.

## Правила для уроков

- Один набор = один урок курса. Название: `Урок 1.2`, `Урок 1.3` и так далее,
  id в том же стиле: `lesson-1-2`, `lesson-1-3`.
- Основная лексика берётся из списка слов урока целиком, без сокращений.
- Дополнительная лексика (`extra`) — слова из текстов, примеров и заданий урока,
  которых нет в основном списке. Сначала самые частые, ориентир 25 слов, но полезные
  слова, встретившиеся один раз, тоже можно включить. Предлоги, союзы и артикли
  не включаются.
- Основные слова могут повторяться между уроками: если слово из списка нового урока
  уже есть в основной лексике предыдущего, в новый набор оно всё равно добавляется с той же
  строкой `gr` (предложения и грамматика общие, по ключу `gr`). В сборном наборе «Custom»
  повторы схлопываются: слово берётся один раз, из первого отмеченного урока.
- Дополнительные слова переносятся: слово из дополнительной лексики предыдущего
  урока, попавшее в список нового урока, добавляется в `words` нового урока и
  убирается из `extra` предыдущего. Дополнительное слово тоже не должно повторять
  ни основное, ни дополнительное слово другого урока.
- Внутри одного набора дубликаты запрещены.
- Если материалов урока нет, дополнительную лексику можно собрать из текстов учеников (так сделан
  урок 3.1: рассказы «О себе» к устному экзамену): берутся слова, встретившиеся минимум в трёх
  текстах и отсутствующие в лексике курса; служебные слова, числительные, имена и слова из фраз
  курса не берутся.
- Урок с числительными (3.2): основная лексика — числительные из раздаточной таблицы (1–20, десятки,
  сотни), без части речи, тема `num`; формы множественного числа и спряжения им не нужны.
- Предлоги в основной лексике (урок 4.1: предлоги из презентации к уроку 3.4): без части речи, тема `prep`,
  составные записываются целиком (`πάνω σε`, `κάτω από`, `πριν από`). Одиночные наречия `πάνω`, `κάτω`, `δίπλα`,
  `κοντά` из дополнительной лексики при этом убраны (см. следующее правило).
- Одиночное слово не включается в дополнительную лексику, если оно уже входит в словосочетание
  или фразу из лексики курса (любого урока): `Από πού είστε;` делает отдельное `πού;` лишним.
- Порядок слов в `words` — как в материалах урока; режим карточек без
  перемешивания идёт в этом порядке.

## Грамматика: `grammar.js`

Режимы «Грамматика: пишем» и «Грамматика вслух» берут формы множественного числа и спряжения из `grammar.js`:

```js
window.GRAMMAR = {
  plural: { "ο άντρας": "οι άντρες", "το νερό": null },
  verbs: {
    "γράφω": { c: "1", ru: ["я пишу", "ты пишешь", "он пишет", "мы пишем", "вы пишете", "они пишут"] },
    "λέω":   { f: ["λέω", "λες", "λέει", "λέμε", "λέτε", "λένε"], ru: [...] }
  }
};
```

- У каждого существительного (`pos: "n"`) должна быть запись в `plural`: форма множественного
  числа с артиклем или `null`, если тренировать нечего (неисчисляемое, только множественное
  число, имя собственное). Основа и окончание вычисляются приложением.
- У каждого однословного глагола (`pos: "v"`) должна быть запись в `verbs`: группа `c`
  (`"1"` — на -ω, `"2a"` — на -ώ/-άω, `"2b"` — на -ώ/-είς) или шесть форм `f` явно для
  неправильных глаголов (варианты через ` / `), плюс шесть русских форм `ru` с местоимением
  в порядке я, ты, он, мы, вы, они.
- Ключи — ровно строки `gr` из `words.js`. Фразы (`μου αρέσει`) записей не требуют.

## Упражнения на падежи и предлоги: `grammar.js`, поля `cases`, `gen`, `prep` и `mix`

Те же режимы «Грамматика: пишем» и «Грамматика вслух» берут упражнения на падежи из
`window.GRAMMAR.cases` (винительный) и `window.GRAMMAR.gen` (родительный), формат одинаковый: ключ —
строка `gr` существительного из `words.js`, значение — список троек `["предложение с пропусками",
"полное предложение", "перевод"]`. Пропуски обозначаются подчёркиваниями: `"Βλέπω τ__ πατέρ__."` →
`"Βλέπω τον πατέρα."`, `"Το σπίτι τ__ φίλ__ μου."` → `"Το σπίτι του φίλου μου."`; текст вне
подчёркиваний должен совпадать с полным предложением по порядку, и каждый пропуск должен быть
непустым (режим «Грамматика: пишем» ставит на его место поле ввода; если окончание отпадает целиком, как
у `ο παππούς → τον παππού`, пропуск захватывает часть основы: `τ__ παππ___`). Это проверяет
`scripts/check-words.js`. Пропускают артикль (в том числе внутри στον/στην/στο и неопределённый
έναν/μία/ένα) и окончание существительного; сдвиг ударения в родительном падеже показывается в
основе (`δασκάλ__` → `του δασκάλου`). Упражнения не обязательны для каждого слова. Предложения не зависят
от выбранного набора: берётся вся основная лексика курса. Сеанс из 25 заданий собирается по кругу из
видов (винительный, родительный, предлоги, множественное число, спряжение; в голосовом режиме без
множественного числа), внутри вида упражнения перемешаны, так что новые упражнения стоит добавлять
с оглядкой на разнообразие родов и чисел. Если у слова два упражнения с одинаковым текстом пропусков
(единственное и множественное число), их различает перевод.

Упражнения на предлоги лежат в `window.GRAMMAR.prep`, формат тот же. Пропуск охватывает
предлог вместе с артиклем, слитным или нет: `"Πηγαίνω ___ θάλασσα ___ αυτοκίνητο."` → `"Πηγαίνω στη
θάλασσα με το αυτοκίνητο."` (пропуски `στη` и `με το`); у мужского рода отдельным пропуском идёт
окончание: `"Πηγαίνω ___ φίλ__ μου."` → `με τον`, `ο`. Когда возможны два предлога (στον φίλο μου и
με τον φίλο μου), их различает перевод. Составные существительные (`το μαχαίρι κουζίνας`) в задании на
множественное число получают пропуск только в первом слове; если меняются оба слова (`η ηλεκτρική
κουζίνα → οι ηλεκτρικές κουζίνες`), слово в это задание не берётся.

Комбинированные упражнения («всё вместе», каждое второе задание сеанса) лежат в `window.GRAMMAR.mix`:
ключ — слово курса, основное или дополнительное (обычно глагол предложения), значение — список
четвёрок `["предложение с пропусками", "полное предложение", "перевод", [роли пропусков]]`. Ролей
ровно столько, сколько пропусков, по порядку: `"v:глагол:лицо"` — окончание глагола (глагол из
`verbs`, лицо 0–5: я, ты, он, мы, вы, они; основа в тексте должна совпадать с началом формы, варианты
формы, например -ουν/-ουνε, засчитываются); `"prep"` — предлог, с артиклем (`από το`) или слитный
(`στην`), в том числе составной целиком (`πάνω στο`, `κάτω από το`, `πριν από τη`) и с родительным падежом
(`μέσω`, `εξαιτίας`, `λόγω`: артикль и окончание после них идут отдельными пропусками с ролью `gen`); `"acc:слово"` и `"accp:слово"` — артикль или окончание винительного падежа в единственном
и множественном числе; `"gen:слово"`, `"genp:слово"` — то же для родительного; `"pl:слово"` — артикль
или окончание множественного числа. Слово роли нужно для рода в тексте правила: `"Τ__ παιδι__ τρώ__
μήλα ___ κήπ__."` → `["pl:το παιδί", "pl:το παιδί", "v:τρώω:5", "prep", "acc:ο κήπος"]`.
`scripts/check-words.js` проверяет роли, слова и формы глаголов.

## Предложения: `sentences.js`

Режимы «Отработка лексики» (9 и 10) показывают предложение со словом и просят произнести его
вслух. Предложения лежат в `window.SENTENCES`: ключ — строка `gr` слова из `words.js`,
значение — ровно 5 пар `["греческое предложение", "русский перевод"]`. Каждое слово урока,
основное и дополнительное, включая фразы, должно иметь свои 5 предложений.

- Предложение содержит слово в любой форме и по возможности состоит только из лексики этого
  и предыдущих уроков плюс частых служебных слов (артикли, местоимения, σε/στο, με, από, για,
  και, αλλά, δεν, να, πολύ, τι, πού, πώς, εδώ, τώρα).
- Коротко, 3–8 слов, в основном настоящее время, самые употребительные обороты.
- Пять предложений одного слова заметно различаются, а не отличаются одним словом.
- Числа только словами: распознавание речи сверяет слова.
- Русский перевод такой, чтобы по нему можно было восстановить греческую фразу (режим 10).

## Проверка перед публикацией

```sh
node scripts/check-words.js
```

Скрипт печатает число слов в каждом наборе и ошибки: дубликаты внутри набора, слова, повторяющиеся
в двух наборах, одиночные дополнительные слова, входящие в словосочетания, пропуски в `grammar.js`
и слова без пяти предложений в `sentences.js`. Ошибок быть не должно,
при их наличии скрипт завершается с ненулевым кодом.

После правки `words.js`, `sentences.js`, `grammar.js` или `index.html` обновите номер сборки в
`index.html`: он стоит в четырёх местах, `<meta name="build" content="...">`,
`<script src="words.js?v=...">`, `<script src="sentences.js?v=...">` и
`<script src="grammar.js?v=...">`, и должен совпадать. Удобно ставить дату с порядковым номером, например `2026-10-19-5`:

```sh
sed -i '' 's/2026-10-19-5/2026-10-20-1/g' index.html
```

По этому номеру приложение при каждом открытии сверяется с сервером и само
перезагружается, если вышла новая сборка. Состояние экрана и текущего упражнения
перед перезагрузкой сохраняется в `sessionStorage` и восстанавливается после неё,
так что обновление не сбивает процесс. Без смены номера телефоны могут до
десяти минут показывать старую версию из кеша GitHub Pages.

Словарь (кнопка на главном экране над режимами, открывает отдельный экран) строится автоматически из слов выбранного
набора с учётом включённой лексики, частей речи и тем, отдельно его править не нужно. Проверьте
только, что новые слова записаны с артиклем (ο, η, το, οι, τα): при сортировке артикль пропускается.
