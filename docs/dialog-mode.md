# Режим 11 «Диалог»: разговор по-гречески с Claude

Добавлен 2026-11-03 (сборка 2026-11-03-11). Ученик выбирает тему и переписывается по-гречески
с моделью Claude, которая держится в рамках слов выбранного набора. Код: раздел «режим 11» в
`index.html` (`startDialog`, `dialogSend`, `renderDialog`, `claudeRequest`).

## Где доступен

- Только при введённом ключе API в настройках (раздел «Диалог»). Без ключа режима нет в списке,
  на главном экране есть строка-подсказка.
- Не на iOS: там не работает распознавание речи в браузере (`docs/ios-speech-recognition.md`),
  режим скрыт даже с ключом; в настройках вместо поля ключа пояснение.
- В браузерах без Web Speech API (Firefox) доступен, но только с клавиатуры.

## Ключ и модель

Ключ API из консоли Anthropic (platform.claude.com → API Keys) хранится в `store.settings.claudeKey`
(localStorage этого браузера) и уходит только в запросах на `api.anthropic.com`. Это отдельный от
подписки Claude счёт с предоплатой; на ключ стоит поставить месячный лимит расходов. Кнопка
«Проверить ключ» делает короткий запрос и показывает ответ модели.

Модель выбирается в настройках: `claude-opus-5-5` (по умолчанию) или `claude-haiku-5-5`. Оценка
стоимости реплики с полным списком слов набора в подсказке: Opus около 2 центов, Haiku около
0,06 цента; системная подсказка помечена `cache_control`, так что при повторных репликах её чтение
дешевле.

## Запрос

`POST https://api.anthropic.com/v1/messages` прямо из страницы, заголовки `x-api-key`,
`anthropic-version: 2026-10-21`, `anthropic-dangerous-direct-browser-access: true` (без него API
отвергает запросы из браузера). Для Opus и Sonnet добавляются `fallbacks: "default"` и заголовок
`anthropic-beta: server-side-fallback-2026-07-01` (серверная запасная модель при отказе
классификаторов); если API вернёт 400 с упоминанием fallback, запрос повторяется без них.

Тело: `system` с правилами и списком слов (`dialogSystem()`), история `messages`,
`output_config.effort: "low"`, структурированный ответ `output_config.format` по схеме
`DIALOG_SCHEMA`:

| Поле | Что |
|---|---|
| `reply` | реплика по-гречески, 1–2 коротких предложения, всегда с вопросом в конце |
| `translation` | русский перевод реплики (показывается по кнопке «Перевод») |
| `new_words` | слова вне списка, не больше двух, с переводом |
| `correction`, `corrected` | объяснение ошибки ученика по-русски и его фраза в исправленном виде; пустые, если ошибок нет |

Первый запрос отправляется со служебной репликой «Начни разговор…», которая в чате не
показывается. В историю ответ модели кладётся как есть (JSON-строка), чтобы она видела свой формат.

## Подсветка слов

`dialogKnown()` собирает известные ученику формы: слова набора, их множественное число и
спряжение из `grammar.js`, все слова предложений режимов 9–10 из `sentences.js` и список служебных
слов `DIALOG_COMMON`. В реплике модели слово вне этого списка подчёркивается пунктиром
(«нет в наборе»), объявленное моделью новое слово — синим пунктиром. Это проверка на нашей
стороне, независимая от того, что модель обещала.

## Ввод

Поле ввода плюс кнопка микрофона (где есть распознавание): распознанный текст попадает в поле,
ученик проверяет и отправляет. Ошибки запроса показываются под чатом; текст неотправленной
реплики возвращается в поле. Диалог сохраняется в `sessionStorage` при перезагрузке на обновление.

## Темы

`DIALOG_TOPICS` в `index.html`: id, название, описание и абзац для системной подсказки. Пока одна
тема, «О себе и о семье». Чтобы добавить тему, достаточно новой записи в этом списке.

## Что не проверено

Весь поток проверен в Playwright с подменённым ответом API. С реальным ключом на 2026-11-03 режим
не запускался: ответ модели, качество удержания лексики, совместимость `fallbacks` со
структурированным ответом и фактическую стоимость нужно проверить при первом запуске.
